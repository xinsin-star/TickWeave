# TickWeave 0.6.1

## 版本升级

- 适配 Minecraft 26.2。构建产物为 `tickweave-26.2-0.6.1.jar`；Minecraft 26.1.2 请继续使用 0.6.0 版本。
- Fabric API 更新至 `0.161.0+26.2`。客户端设置页面适配 MaLiLib `0.29.6`，可选的 Mod Menu 适配 `20.0.3`。
- 适配 Minecraft 26.2 的客户端界面与翻译 API，修复设置页面打开和方块名称显示相关的编译问题。

## 升级方法

1. 将 Minecraft 与 Fabric 环境升级到 26.2，并安装对应版本的 Fabric API。
2. 从客户端 `mods` 文件夹移除旧版 TickWeave JAR，放入 `tickweave-26.2-0.6.1.jar`；需要设置页面时安装 MaLiLib `0.29.6`。Mod Menu `20.0.3` 为可选项。
3. 多人游戏服务器也需替换为同一个 TickWeave JAR，并安装适配 26.2 的 Fabric API。MaLiLib 和 Mod Menu 只在客户端使用。
4. 可保留已有的 `config/tickweave.json`；首次启动后检查可视化大小、颜色和快捷键设置。

此版本延续活塞事件顺序、深度、红石线和 0t 红石块输出的现有可视化功能。26.2 分支的推送会生成 CI 构建产物；GitHub Release 仅在代码进入 `main` 且构建成功后发布，标签为 `0.6.1`。
